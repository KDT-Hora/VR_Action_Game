# Quickstart(検証手順)

## 前提
- Unity 6 LTS、Meta Quest 3/3S + PC接続(Link)、最新のMeta XR SDK
- 実機がない場合は `FixtureScanProvider` を使用

## 1. 生成コアの検証(実機不要)
1. `Core/` のテストを実行(Unity Test Runner の EditMode)
2. 期待: 決定論テスト(同一シード100回一致)、到達可能性テスト(全て成功)が緑

## 2. 机上プロトタイプ(Phase 1〜2)
1. Unityで `Game/` を開き、Fixtureシーンを再生
2. 期待: 小さな子が机上に表示され、スティックで移動、剣で攻撃、覗き込める

## 3. 実スキャン(Phase 3〜)
1. ヘッドセットをPC接続して起動、部屋スキャンを実施
2. 期待: 1分以内にステージが生成され、境界に近づくとパススルーが自動表示される

## 4. 保存・共有
1. クリア後にセーブ→再起動で再開できること
2. ShareFileを別環境で読み込み、同一ステージになること
